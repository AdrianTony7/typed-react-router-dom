# Changelog - v1

All notable changes to `typed-react-router-dom` in version 1.x are documented here.

---

## [1.0.0] - 2026-09-10

### Breaking Changes

- **Removed `paramKeys`**:
  - Removed `paramKeys` from the `Route` interface.
  - Dynamic route parameters are now strictly inferred from the `path` string literal (e.g. `path: '/users/:id'`).
  - Removed runtime and type fallbacks for `route.paramKeys` across `RouteParams<R>`, `RouteHelper.constructHref`, `RouteHelper.isRouteMatchByUrl`, and `AppRouterService.navigateToRoute`.
- **Removed `queryKeys`**:
  - Removed `queryKeys` from the `Route` interface and `RouteQueryParams<R>`.
  - Use `queryType` for compile-time typed query parameters.
- **Removed `<AppLink />` & `AppLinkProps`**:
  - Completely removed `<AppLink />` and `AppLinkProps` in favor of `<TypedLink />` and `<Link />` (and `TypedLinkProps`).
  - Removed `router.AppLink` from `createTypedRouter`. Use `router.TypedLink` or `router.Link`.
  - Removed the `src/AppLink.tsx` file.

### Migration Guide from 0.x

1. **Path Parameters**:
   Remove `paramKeys` from your route definitions:
   ```ts
   // Before (0.x)
   USER_DETAIL: {
     path: '/users/:id',
     name: 'User Detail',
     paramKeys: ['id'] as const,
   }

   // After (1.0.0)
   USER_DETAIL: {
     path: '/users/:id',
     name: 'User Detail',
   }
   ```

2. **Query Parameters**:
   Replace `queryKeys` with `queryType`:
   ```ts
   // Before (0.x)
   USER_DETAIL: {
     path: '/users/:id',
     queryKeys: ['tab', 'page'] as const,
   }

   // After (1.0.0)
   USER_DETAIL: {
     path: '/users/:id',
     queryType: {} as { tab?: 'profile' | 'settings'; page?: number },
   }
   ```

3. **Link Component**:
   Replace `<AppLink />` with `<TypedLink />` or `<Link />`:
   ```tsx
   // Before (0.x)
   import { AppLink } from 'typed-react-router-dom';
   <AppLink route={routes.USER_DETAIL} params={{ id: '42' }}>User</AppLink>

   // After (1.0.0)
   import { TypedLink, Link } from 'typed-react-router-dom';
   <TypedLink route={routes.USER_DETAIL} params={{ id: '42' }}>User</TypedLink>
   // or
   <Link route={routes.USER_DETAIL} params={{ id: '42' }}>User</Link>
   ```
